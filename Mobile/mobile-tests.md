# Testes Mobile - EBAC Shop

Esta pasta contempla a estrutura prevista para automação de testes mobile utilizando WebdriverIO e Appium.

## Objetivo

Validar os principais fluxos mobile da aplicação EBAC Shop, garantindo que funcionalidades essenciais estejam disponíveis e funcionando corretamente em dispositivos móveis.

## Cenários previstos

- Acessar catálogo de produtos;
- Visualizar detalhes de um produto;
- Adicionar produto ao carrinho;
- Validar acesso à área Minha Conta;
- Validar tentativa de login inválido.

## Ferramentas previstas

- WebdriverIO
- Appium
- Android Emulator
- Node.js

## Observação

A estrutura foi criada para representar a camada mobile do projeto final, considerando a estratégia de testes definida no documento do TCC.
