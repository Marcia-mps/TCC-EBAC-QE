# TCC EBAC QE

Projeto final do curso Engenheiro de Qualidade de Software da EBAC.

## Objetivo

Este repositório reúne a estratégia de qualidade, documentação e estrutura de automação para validação do e-commerce EBAC Shop.

## Estrutura do projeto

```text
TCC-EBAC-QE/
├── UI/
├── API/
├── Mobile/
├── Performance/
├── docs/
├── .github/workflows/
└── README.md

```md
## Camadas de teste

- UI: testes automatizados de interface web com Cypress.
- API: testes automatizados da API de cupons com Supertest.
- Mobile: testes automatizados mobile com WebdriverIO/Appium.
- Performance: testes de performance com K6.
- docs: documentação, evidências e arquivos complementares.

## Ferramentas previstas

- Cypress
- Supertest
- WebdriverIO/Appium
- K6
- GitHub Actions
